# Phân tích và đặc tả yêu cầu – Hệ thống quản lý và bán hàng thời trang

Thư mục `01-Requirement-Analysis` dành cho tài liệu phân tích yêu cầu của **Đồ án liên ngành Công nghệ thông tin (2026)**.

## Tài liệu dự kiến

- **Software Requirements Specification (SRS):** mô tả yêu cầu chức năng, yêu cầu phi chức năng, các ràng buộc và đặc tả Use Case.
- **Sơ đồ nghiệp vụ:** Use Case Diagram, Activity Diagram và Sequence Diagram (nếu được đính kèm trong tài liệu SRS).

**Trạng thái:** Chưa tải file SRS lên GitHub. README này sẽ được cập nhật liên kết trực tiếp sau khi tài liệu được bổ sung.

Tài liệu được tổng hợp và biên tập từ báo cáo đồ án thực hiện theo nhóm; không mặc định toàn bộ nội dung là sản phẩm cá nhân.
