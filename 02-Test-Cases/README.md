# Test Cases

Tài liệu gốc: `CV_TestCase_ĐALN(3).xlsm` (Excel macro-enabled workbook).

- Có các cột: nhóm chức năng, mã ca kiểm thử, mô tả, dữ liệu, bước thực hiện, kết quả mong đợi, kết quả thực tế và kết luận.
- Phần thống kê của workbook ghi nhận **177 ca**: 140 Đạt, 15 Không đạt, 22 Chưa test, 0 Không chạy.
- Bảng Excel bao phủ phạm vi rộng hơn ba Use Case được chọn làm trọng tâm trong báo cáo kiểm thử học phần.

**Trạng thái:** file Excel gốc chưa được đưa vào repository bằng kết nối hiện tại. Hãy tải lên bằng GitHub > Add file > Upload files sau khi kiểm tra dữ liệu cần ẩn. Không sử dụng file thay thế tự tạo từ nội dung suy đoán.
